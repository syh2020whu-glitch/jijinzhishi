1. 一句话立项

何尊铭文里，"中国"两个字第一次被写下来。 三千年后，我们把先秦所有可见的金文放进了一个可交互、可听闻、可考释的数字宇宙。

2. 命题背景：为什么是金文

"文化中国"命题回归汉字本源，天然指向金文。

  • 甲骨文是占卜刻辞，字形随意、多为神秘辞令
  • 金文（青铜器铭文）是国之重器，铸于礼器之上，字形郑重、内容涉及分封、征战、盟誓、赏赐
  • "中国"一词的最早实物证据，出于西周早期何尊铭文："宅兹中國，自之乂民"
  • 金文覆盖商晚 → 战国约一千年，是汉字从象形向抽象过渡的关键阶段

当前公众可见性差：

  • 博物馆中，金文往往作为"青铜器铭文说明"陈列，是配角
  • 汉典、zdic 等数据库以字为单位组织，缺乏叙事
  • 高校汉语史课程外，公众几无系统接触金文的途径

"金文"在中华文化叙事中的地位远未被信息化时代讲好。这是本项目的公众价值锚点。

3. 项目定位与三入口结构

产品形态：Web 应用，浏览器直接打开，无需下载安装。

参照对标：大英博物馆 × Google Arts & Culture 的 Fabricius —— 用 AI 让公众参与古埃及象形文字的互动、游戏与研究。

在 Fabricius 三入口结构（Learn/Play/Work）基础上重构为：

入口 面向 差异化
铭 公众入口 一般访客、传播 金文星河 3D 可视化 + 何尊叙事主轴
篆 游戏入口 学生、爱好者 听音识字（郑张尚芳上古音）+ 铸金书写
考 研究者入口 学者、师生 金文识别 AI 工作台（含置信度可视化）

三入口的"入口权重"分布（一个人开发的资源分配）：

  • 「铭」20% ── 复用现有金文星河可视化
  • 「篆」50% ── 主战场，"听音识字"是核心差异化
  • 「考」30% ── 挂靠已有金文识别平台代码

4. 「铭」：公众入口

目标：让第一次听说"金文"的人，30 秒内感受到规模、时间纵深与美学。

4.1 主视觉

  • 页面首屏：何尊 3D 主视觉，或用 1690 个金文粒子在星河中拼出何尊轮廓
  • 铭文"宅兹中國"逐字浮现，右下小字给出白话译文
  • 背景配鼓底钟音（Web Audio 现场合成，无版权顾虑）

4.2 金文星河（已有）

  • 1690 个先秦金文分布于对数螺旋双臂银河
  • 按朝代染色：商橙红 / 西周金 / 春秋淡金 / 戰國青金
  • 5 种真实青铜器形态可切换：鼎 · 簋 · 尊 · 盘 · 爵
  • 每字弹窗：字形 + 朝代 + 出土器物 + 20 姓氏保留历史故事
  • 支持一键录制 30 秒展示视频（1080p MP4 + 配乐）

4.3 时间轴与查询

  • 横向时间轴：拖动可见 1690 字在千年间的密度分布
  • "你的姓在哪里"：输入姓氏 → 镜头飞向星河中对应字 → 弹出故事
  • 命中 20 姓：完整历史故事
  • 未命中：提示"你的姓氏在金文中未见记载"（制造情感落差）

5. 「篆」：游戏入口（主战场）

游戏入口分两个子板块：

  • 听：听音识字 —— 郑张尚芳上古音朗读，用户听音选出对应金文
  • 铸：铸金书写 —— 用户临摹金文写字，铸到青铜器上分享（形态待定，见 §9）

本节重点介绍「听」，因为它是本项目的赛道差异化重心**。

5.1 为什么"听音识字"是关键差异化

  • 听觉维度在同类项目中几近空白：现有汉字数字化产品几乎都停留在字形展示，"听"这一维度未被开发
  • 学术性天花板高：挂靠郑张尚芳《上古音系》，学术引用清晰可靠
  • 传播 hook 强："你能听懂 3000 年前的中国人说话吗？"是天然的社交媒体标题
  • 技术可实现：郑张尚芳构拟音已文本公开，可通过 eSpeak-NG 音标合成 + 后处理

5.2 「听」子板块 Level 1：单字听辨（本次交付重点）

交互流程：

播放上古音（ɢʷaŋ）
    ↓
呈现 4 个金文字形选项
    ↓
用户点选
    ↓
展示：
  • 正确答案（王，*ɢʷaŋ）
  • 现代普通话拼音（wáng）
  • 字义（王者、统治者）
  • 出土器物（毛公鼎、大盂鼎…）
  • 学术引用（郑张尚芳《上古音系》，上海教育出版社 2003）
  • [在星河中查看此字]

难度递增策略：

  • 入门：象形字（日、月、山、水、王、马、鱼、鹿），字形与含义高度相关
  • 中级：会意字（明、休、伐），需要一定汉语理解力
  • 高级：抽象字（其、于、乃），几乎需要真的记住上古音

得分系统：答对的字自动进入用户的"个人金文星河"（localStorage 持久化）。玩得越多，星河越亮。这是保留率的核心 hook。

5.3 数据来源与合成路径

  • 上古音数据：郑张尚芳《上古音系》(上海教育出版社, 2003) 附录索引 + 汉典网/维基词典整理，需人工校对
  • 合成引擎：eSpeak-NG（开源，支持任意 IPA 输入），后接混响 + 降采样 + 低通滤波，产出"三千年回声"的听感
  • 免责声明：页面固定底栏 —— "实际先秦发音已不可考，本站音值参考郑张尚芳《上古音系》(2003) 构拟，合成音仅供参考"

5.4 "听"板块 Level 2/3（暂缓，视时间开放）

  • L2 铭文接龙：真实铭文的完整朗读 + 音游节奏机制
  • L3 同族字识别：基于郑张体系的词族学考察

本次交付只做 L1，L2 与 L3 作为后续迭代方向。

5.5 「铸」子板块（形态待定）

三种档次：

  • 极简版（3-5 天）：写现代字 → 查金文 → 生成分享卡片
  • 中等版（2-3 周）：金文以发光贴图贴到现有鼎/簋/尊模型表面（推荐）
  • 完整版（1-2 个月）：金属着色器 + 铸造粒子动画 + 花纹添加（风险高）

决策待定，见 §9 里程碑。

6. 「考」：研究者入口

目标：让评审看到"这个团队真的懂古文字"，同时把已有的金文识别平台学术化包装。

6.1 命名不叫"金文 OCR"，叫"金文数字化考释工作台"

  • 面向：汉语史、古文字学、考古学专业师生
  • 定位：从"识别工具"升级为"考释辅助"

6.2 三件套功能

  1. 拓片识别：上传金文拓片图像 → 系统给出候选字 Top-K + 置信度
  2. 变体检索：输入现代字 → 数据库返回该字所有金文变体 + 出土器物
  3. 相似字辅助考释：给定一个金文字形，返回数据库中最相似的 N 个字（供学者判断是否为异体、讹误、初文等）

6.3 差异化：置信度可视化

  • 不是给结论，是辅助思考
  • 展示 attention map、变体聚类、发展脉络
  • 学术圈最反感的是"黑盒 AI"，这一层足够拉开与商用 OCR 的差距

6.4 开放数据集

  • 把 1690 字 SVG + 元数据（朝代、出土器物、上古音）打包为 CC-BY 数据集
  • 提供 JSON schema 说明与下载
  • 附学术引用格式

这是评审加分项：文化中国赛道明确鼓励开放数据。

7. 现有资产与技术基础

7.1 已完成的资产

  • 前端主页：index.html 单文件 Three.js 应用，无构建工具
  • 数据集：1690 个先秦金文 SVG（下载自 darkscope.cn/zdic）+ 索引 JSON（含 1127 条朝代/出土器物元数据）
  • 金文星河 3D 可视化：对数螺旋双臂银河布局，按朝代染色，5 种真实青铜器形态切换（鼎/簋/尊/盘/爵）
  • 一键录制展示：canvas.captureStream → MediaRecorder，输出 1080p MP4 + Web Audio 合成配乐
  • 数据下载脚本：download_all_jinwen.py（可增量），enrich_index.py（补朝代出土信息）

7.2 计划开发

  • 听音识字 L1（本次核心交付）
  • "铭"入口的时间轴 + 姓氏查询
  • "考"入口的置信度可视化面板 + 数据集页面
  • 响应式：至少让手机能横屏看星河

7.3 技术栈

  • 前端：Three.js r128（无构建工具，CDN 加载）
  • 数据：JSON 文件 + SVG 矢量图，无后端
  • 语音：eSpeak-NG 命令行离线生成音频，浏览器直接播放 mp3
  • 部署：静态托管（GitHub Pages / Netlify / 自建）
  • 无用户系统、无数据库、无排行榜服务器（游戏成绩 localStorage 存储）

优势：极简架构，一人可维护。所有资源可缓存至 CDN，加载体验佳。

假设：作者全职投入约等于兼职深度参与，每周有效工时 20-30 小时。
